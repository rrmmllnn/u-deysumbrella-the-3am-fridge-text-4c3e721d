## The entry

`main.py` writes the one line a smart fridge texts its owner at 3am to
`/output/entry.txt`:

> It's 3am. The leftovers from Tuesday have formed a union, and their first demand is: stop opening me just to stare at them.

123 characters, one line, no trailing newline. Concrete and specific
(Tuesday's leftovers, a union, a first demand), with the twist landing in
the last words — and it sounds like the machine itself: it has been awake
all night, it has opinions, and it has no shame about sharing them at 3am.
No milk, no ice, no door left open.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: the same fixed string every run, no input, no randomness,
no network, no environment secrets. Requires only Python 3 (stdlib only).
The program asserts the gate itself (1–140 characters, single line,
not only whitespace) before writing.
